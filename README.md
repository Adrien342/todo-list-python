# 📝 Python To-Do List Application

A simple and beginner-friendly command-line To-Do List application built with Python.  
This project allows users to manage daily tasks directly from the terminal.

---

## 🚀 Features

- ➕ Add new tasks
- 📋 View all tasks
- ❌ Delete tasks by number
- ⚠️ Input validation and error handling
- 🔁 Interactive menu system

---

## 🛠️ Technologies Used

- Python 3
- Git
- GitHub

## ▶️ How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/adrien342/todo-list-python.git
```

### 2. Navigate into the project folder

```bash
cd todo-list-python
```

### 3. Run the program

```bash
python todo.py
```
